# Course Code: CML3112
## Program: BSCE-J (Civil Engineering)
### Cohort: CML3112

### 1. Project Description
This project covers data engineering metrics for structural safety evaluation by processing a 300-row automated log file tracking concrete slab crack width propagation metrics.

### 2. Files List
* `24_UG_654_BSCE_J_W04.ipynb` - My completed Week 4 data processing assignment notebook containing evaluation code configurations, calculations, and explanations.
* `site_inspection.log` - The supplied source Microsoft Excel Comma-Separated Values dataset tracking localized crack widths.
* `README.md` - The repository instruction and declaration document.

### 3. How to Run
1. Open Google Colab in a web browser.
2. Navigate to the 'Upload' tab and choose the notebook file `24_UG_654_BSCE_J_W04.ipynb`.
3. Open the sidebar File panel area by clicking the folder icon on the far left.
4. Click the upload button to upload `site_inspection.log` straight into session storage.
5. Choose 'Runtime' from the top menu area and click 'Restart and run all' to execute all configuration blocks sequentially from top to bottom.
